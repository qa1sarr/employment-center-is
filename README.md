# Жұмыспен қамту орталығының ақпараттық жүйесі

Әл-Фараби атындағы ҚазҰУ, «Ақпараттық жүйелер» кафедрасы — зертханалық жұмыстар жобасы.

## Жоба туралы

Жүйе жұмыс іздеушілерді жұмыс берушілердің вакансияларымен AI негізінде сәйкестендіреді. Онлайн тіркелу бұрыннан бар, бірақ вакансия іздеу қолмен жүргізіледі. Жоба осы кемшілікті жоюға бағытталған: резюмені автоматты талдап, жекелендірілген вакансия ұсынады.

## Пайдаланушылар

- Жұмыс іздеуші
- Жұмыс беруші
- Жұмыспен қамту маманы
- Жүйе әкімшісі

## Репозиторий құрылымы

- `README.md`
- `docs/` — талаптар, Use Case және UML диаграммалары
- `database/` — SQL Server деректер қоры

## Деректер қоры

Class диаграммасы негізінде 12 кестелі деректер қоры жасалды: `database/schema_mssql.sql` (Microsoft SQL Server, T-SQL).
