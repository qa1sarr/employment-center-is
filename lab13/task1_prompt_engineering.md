# 1-тапсырма. Prompt Engineering (жобамыздың тақырыбымен)

ChatGPT (немесе Claude) ішінде үш сұранысты БІРІНЕН СОҢ, жаңа чатта орындаңыз да, жауаптарын төмендегі кестеге қысқаша жазыңыз.

## Сұраныстар

1. **Қарапайым Prompt**
   `Вакансия мен түйіндеменің сәйкестік балы туралы түсіндір.`

2. **Контексті Prompt**
   `Вакансия мен түйіндеменің сәйкестік балы туралы 2-курс студентіне түсінікті тілмен түсіндір.`

3. **Құрылымдық Prompt**
   `Вакансия мен түйіндеменің сәйкестік балы туралы анықтама, 3 қағида және Python мысалы түрінде түсіндір.`

## Салыстыру кестесі (өзіңіз толтырыңыз)

| Критерий                  | Қарапайым | Контексті | Құрылымдық |
|---------------------------|-----------|-----------|------------|
| Жауап ұзындығы (шамамен)  |           |           |            |
| Түсініктілігі (1-5)       |           |           |            |
| Құрылымы бар ма           |           |           |            |
| Python мысалы бар ма      |           |           |            |
| Жобаға пайдалылығы (1-5)  |           |           |            |

## Қорытынды үлгісі
Қарапайым сұраныс жалпы, құрылымсыз жауап береді. Контексті сұраныс аудиторияға бейімделген, түсінікті тіл береді. Құрылымдық сұраныс нақты форматты (анықтама, қағидалар, код) талап еткендіктен, ең толық әрі пайдалануға ыңғайлы жауап береді. Тиімді Prompt — мақсатты, аудиторияны және жауап форматын нақты көрсететін Prompt.
