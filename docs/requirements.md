# Жүйеге қойылатын талаптар

## 1. Stakeholder-лер (мүдделі тараптар)

| № | Stakeholder | Мүддесі |
|---|-------------|---------|
| 1 | Жұмыс іздеуші | Қысқа мерзімде өз біліктілігіне сәйкес жұмыс табу |
| 2 | Жұмыс беруші | Бос орынды тез әрі сапалы кандидатпен жабу |
| 3 | Жұмыспен қамту орталығының басшылығы | Қызмет көрсету сапасын және жұмыспен қамту көрсеткіштерін арттыру |
| 4 | Еңбек және әлеуметтік қорғау министрлігі (жергілікті атқарушы орган) | Аймақтық жұмыссыздық статистикасын бақылау және мемлекеттік бағдарламаларды іске асыру |
| 5 | Оқыту орталықтары | Қайта даярлау курстарына тыңдаушылар тарту |

## 2. Функционалдық талаптар

| ID | Талап |
|----|-------|
| FR-01 | Жүйе жұмыс іздеушінің онлайн тіркелуін қамтамасыз етуі тиіс |
| FR-02 | Жүйе жұмыс іздеушіге резюме жүктеу және өңдеу мүмкіндігін беруі тиіс |
| FR-03 | Жүйе жұмыс берушінің вакансия тіркеуі мен басқаруын қамтамасыз етуі тиіс |
| FR-04 | Жүйе резюме мен вакансияны AI негізінде автоматты сәйкестендіруі тиіс |
| FR-05 | Жүйе вакансияға өтінім беру мүмкіндігін қамтамасыз етуі тиіс |
| FR-06 | Жүйе пайдаланушыларға SMS/email/push хабарламалар жіберуі тиіс |
| FR-07 | Жүйе қайта даярлау курстарына онлайн жазылу мүмкіндігін беруі тиіс |
| FR-08 | Жүйе үміткер, вакансия, компания бойынша іздеу және сүзгілеу функциясын қамтамасыз етуі тиіс |
| FR-09 | Жүйе кезең, аймақ, мамандық бойынша есептер мен статистика генерациялауы тиіс |
| FR-10 | Жүйе пайдаланушылардың авторизациясын және рөлге сәйкес құқықтарын тексеруі тиіс |

## 3. Функционалдық емес талаптар

| ID | Санат | Талап |
|----|-------|-------|
| NFR-01 | Қауіпсіздік | Дербес деректер «Дербес деректер туралы» заңнамаға сәйкес қорғалуы тиіс |
| NFR-02 | Өнімділік | Жүйе бір мезгілде кемінде 1000 белсенді пайдаланушыға қызмет көрсетуі тиіс |
| NFR-03 | Қолжетімділік | Жүйенің жұмыс уақыты (uptime) 99.5%-дан кем болмауы тиіс |
| NFR-04 | Масштабталушылық | Пайдаланушылар саны артқан сайын жүйе қосымша ресурстармен кеңейтілуі тиіс |
| NFR-05 | Usability | Интерфейс интуитивті және мобильді құрылғыларға бейімделген болуы тиіс |
| NFR-06 | Compatibility | Жүйе веб-браузерлерде және мобильді қосымшада бірдей жұмыс істеуі тиіс |

## 4. User Story-лер

- **US-01:** Мен жұмыс іздеуші ретінде өз резюмемді жүйеге жүктегім келеді, себебі жұмыс берушілер мені тезірек тапсын.
- **US-02:** Мен жұмыс беруші ретінде бос орынды жариялағым келеді, себебі маған сәйкес кандидаттар тезірек табылсын.
- **US-03:** Мен жұмыс іздеуші ретінде маған сәйкес вакансиялардың автоматты ұсынылғанын көргім келеді, себебі уақытымды үнемдей отырып жұмыс табайын.
- **US-04:** Мен жұмыспен қамту маманы ретінде тіркелген азаматтардың тізімі мен мәртебесін көргім келеді, себебі оларға уақытылы қолдау көрсетейін.
- **US-05:** Мен жұмыс іздеуші ретінде қайта даярлау курсына онлайн жазылғым келеді, себебі жаңа дағды үйреніп, жұмыс табу мүмкіндігімді арттырайын.
- **US-06:** Мен жүйе әкімшісі ретінде пайдаланушылар мен олардың рөлдерін басқарғым келеді, себебі жүйенің қауіпсіз әрі тұрақты жұмысын қамтамасыз етейін.
