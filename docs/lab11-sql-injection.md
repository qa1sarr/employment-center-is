# Лаборатория жұмысы №11. SQL Injection зерттеу

**Жоба:** Жұмыспен қамту орталығының ақпараттық жүйесі

## Мақсаты
SQL Injection шабуылының механизмін зерттеу және параметрленген сұраныстар арқылы қорғану.

## Құрылымы (`lab11/`)
| Файл | Міндеті |
|---|---|
| `db_setup.py` | Жадтағы SQLite базасы: `vacancies`, `users` (оқу деректері) |
| `vulnerable_search.py` | ОСАЛ іздеу: сұраныс мәтінді біріктіру арқылы құрылады |
| `secure_search.py` | ҚАУІПСІЗ іздеу: параметрленген сұраныс (`?`) |
| `vulnerable_app.py` / `secure_app.py` | `input()` арқылы интерактивті іздеу |
| `compare.py` | Бірдей енгізулерді екі нұсқаға беріп салыстыру |
| `test_sql_injection.py` | 9 unittest |

## Іске қосу
Репо түбірінен:
```
python -m lab11.vulnerable_app
python -m lab11.secure_app
python -m lab11.compare
python -m unittest lab11.test_sql_injection -v
```

## Тексеру енгізулері
| Енгізу | Осал нұсқа | Қауіпсіз нұсқа |
|---|---|---|
| `аналитик` | 1 жол | 1 жол |
| `%' OR 1=1 --` | 9 жол (жабық вакансиялар да) | 0 жол |
| `x' UNION SELECT user_id, email, 0, password_hash FROM users --` | 3 жол (users деректері) | 0 жол |
| `x'; DROP TABLE vacancies; --` | драйвер қатесі (бір execute — бір команда) | 0 жол, кесте сақталды |

## Қорытынды
Пайдаланушы мәнін SQL мәтініне қосуға болмайды, әрқашан параметр ретінде беру керек.
